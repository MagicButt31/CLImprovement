# CLImprovement
A CLI-based self-improvement app. This is my second main project that I'll be working on. And it'll be FREE for everyone (with a computer, unless I can add syncing to phone).

## Getting Started
To even get the app launched, firstly, copy or download the script, and then place it in the directory at which you'll be running it (remember, files will be created in the same directory, so do with that as you will). After that, run the python script. I recommend running it from the terminal.

So, when launching the app, you will be greeted with the screen of:
```shell
What do you want to open ('/help' for commands)? 
```
As you can see, you can put in '/help' for commands. You should do that. Next, what you want to do is to put in '/apps' to find out applications in the climprovement app. Once you have figured out what to use, just put in the name of the app, enter, and you will be able to find the app screen.

### Tasks
On launching tasks, you will be shown:
```shell
Tasks: What do you want to do?  
```
Using /help will still work, so you can see commands.
But also, whenever you use the command /apps in this case, you get to see what you can do in tasks.
```shell
Functions of tasks:

add <task>: literally just adds tasks to save
delete all tasks: removes every single task made
clear <task>: clears one task at a time
complete <task>: completes tasks
```
These let you do what it says you can do.

To start using tasks, enter 'add <tasks>'. This will show you
```shell
When is your task due (format mm/dd/yyyy, and words are fine)?
```
Of course, you have to add tasks. Firstly, enter the name of the task, and then it'll ask you for the task due date. Repeat this until all of your tasks are written down. Once you're satisfied with the tasks you have, enter /finish to finish.

'clear one task' and 'complete task' work about the same as 'add tasks', just that you have to only enter the name of a task that already exists.

FINALLY, 'clear all tasks' and 'view tasks' don't require any specifying tasks, as they affect all tasks at once.
